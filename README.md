# huaweicup2026-submit

“华为杯”第二十三届中国研究生数学建模竞赛（2026）D 题《山区洪涝灾害下无人机运输与通信协同优化》最终提交仓库。

本仓库用于汇总竞赛最终交付材料：

- `paper/`：论文终稿（PDF 及 LaTeX 源文件）
- `code/`：四问求解代码与运行说明
- `results/`：结果文件（按竞赛结果提交模板整理）
- `supporting/`：支撑材料（审计日志、图件、复现说明）

开发协作仓库为 [chendelong277/huaweicup-2026](https://github.com/chendelong277/huaweicup-2026)，本仓库只存放冻结后的提交物。
