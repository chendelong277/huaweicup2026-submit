# Q3 模型与算法

> **三分钟摘要**：本文档给出问题三的数学模型与算法流程：用自由空间传播损耗加地形遮挡损耗计算链路余量，把连续通信需求写成"每个时间片要么直连网关、要么由一架中继同时连通运输机和网关"的约束，并规定中继能耗与资源占用规则。算法部分是一个贪心集合覆盖式的启发式基线，作者明确不宣称全局最优。

## 链路模型

对端点 `a,b` 的三维距离 `d_km` 使用自由空间传播损耗

`L_fspl = 32.44 + 20 log10(f_MHz) + 20 log10(d_km)`。

若 DEM 采样点遮挡视线，附加 `L_obs`；双向链路余量取两个方向允许传播损耗的较小值减总传播损耗。直连状态要求运输机—G01 链路余量非负；中继状态同时要求运输机—中继和中继—G01 两段余量非负。

## 时间片与覆盖

每条运输航段按爬升、巡航和下降构造连续轨迹，并在航段内取 5 个均匀采样点，同时保留服务交接间隙的端点状态。令 `d_pt` 表示时间片 `t` 的直连可用指示，`c_pht` 表示候选中继 `h` 是否同时覆盖运输机和网关，则通信约束为

`d_pt + Σ_h c_pht y_ht >= 1`。

候选中继位置来自运输轨迹点及其局部偏移，离地高度枚举 100、200、300 m，并限制在 DEM 范围及题面最大悬停高度内。

## 中继能耗与资源

中继往返飞行能耗由巡航功率和飞行时间、爬升附加能耗构成；服务能耗为 `(悬停功率 + 通信附加功率) × 服务时长`。中继机和能源组件的任务区间不得重叠，任务结束 SOC 不得低于 0.2，组件充电采用题面两阶段充电规则。

## 算法

1. 读取 Q2 `transport_plan.csv`，重建 DEM 一致的航段和运输轨迹。
2. 对所有时间片计算直连链路；记录通信盲区。
3. 生成候选中继位置—高度并预计算覆盖集合。
4. 用贪心集合覆盖选择中继任务，优先覆盖盲区片段数，再比较最小链路余量和能耗。
5. 进行确定性资源日历检查，并输出通信与资源审计；必要时对 Q2 运输时间做保守平移，重新检查时限。

该算法是可复现启发式基线，不宣称全局最优。通信采样步长、候选位置数量和运输改序均应在进一步实验中做敏感性分析。

## ALNS-Q3-V2（2026-09-25）联合搜索补充

本节描述 `code/alns_q3_v2.py`，不覆盖上文早期贪心基线。以运输架次结构和派发顺序作为解；每次调用 Q2 排程解码器核查货箱、载荷/体积、时限、无人机/电池/SOC/充电；定期或盲区签名显著变化时用双中继覆盖/占用 MILP 做联合解码。按 `(硬违约, WT, 联合 makespan, 总架次, 联合能耗)` 词典序取最终可行解，且在搜索中维护以前两个优化目标 `(WT, 联合 makespan)` 的全部非支配联合可行解；总架次和联合能耗随档案点作为附加诊断字段保存。中继并发代理取每架次五点直连盲区时间窗的峰值，超过库存 2 架则增加硬违约并拒绝恶化移动；失败导向 `relay_shift` 将超载窗内架次后移。此代理不是链路连续性的充分条件；MILP 解码决定内部档案准入，独立 `whli_q3_gate.py` 才提供更严格的 DEM 数值证据（2 s 直连探测、20 s 严格候选筛查、1 s 密检、0.05 s 临界闭包）。`--no-hard-relay-cap` 保留历史软引导口径供消融。严格重装配中继与原 ALNS 五点解码中继是两套方案，Q4 冻结仅采用前者。实验结果见 `results_alns_q3_v2_hardcap_600s/` 与 `results_alns_q3_v2_ablation/` 各运行目录的 `global_audit.json` 与 `decode_log.json`。
