# ALNS-Q3：运输搜索与中继反馈门禁

> **三分钟摘要**：本文档记录 ALNS-Q3 算法的设计与一轮可复现实验：它先搜索运输方案，再用严格的地形视距检查和自动审计脚本筛选候选，最后装配中继方案。100 秒预算的实跑中，重新装配的联合方案与队友 WHLi 的历史最优方案数值完全相同，因此最终仍沿用该历史方案，本轮没有独立发现更优的运输解。读者重点看"本版修复"和"复现实验与结果"两节。术语看不懂可查仓库根目录 `shared/glossary.md`。

## 当前算法

1. ALNS-Q2 搜索货箱组批、机型、架次顺序；资源排程解码器确定运输机、电池和时刻。
2. 用中继代理量引导运输顺序/发车时间的局部搜索。该量仅用于筛选候选，**不是通信可行性证明**。
3. 对 ALNS 候选和 WHLi Q2-v5 暖启动候选进行比较；被选中的实际运输方案先由 WHLi `verify.py` 独立复核运输物理量、货箱与资源约束。
4. 严格 DEM 探测直连盲区。优先对少量中继悬停位置进行**重新计算**的严格链路筛查，再由两架中继机占用 MILP 组合任务；短名单失败时退回完整候选目录。历史位置仅是几何暖启动，不能继承历史覆盖结论。
5. 装配后进行 0.5 s 严格密检和 0.05 s 关键时段加密检查。只有两项均通过才标记 `fully_audited_feasible`。这里的“连续性闭包”是数值密检，不是解析意义上的全时刻证明。

目标遵循硬约束优先；可行方案之间按配送及时性、联合任务完成时间、能耗/架次数比较。代理量用于决定优先检查哪个候选，不进入最终可行方案的目标排序。

## 本版修复

- 把 WHLi 已优化的 RS01 悬停坐标作为候选种子，并对**当前运输架次**重新运行严格 DEM 覆盖筛查；解决原始坐标在 0.05 s 密检出现约 −3.21 dB 断链的问题。
- 先检查 4 个位置的短名单，失败才筛查完整目录。对相同输入，严格门禁预审耗时由约 49.5 s 缩短至约 12.0 s（两次均不含密检）。
- 连续性检查显式读取本轮 Q2 运输 JSON 和数据根目录，避免误用 WHLi 脚本的默认历史路径。
- 运输硬约束审计现在针对实际进入 Q3 的候选运行，不再把 ALNS-Q2 基线审计错误归于 WHLi 暖启动。
- 候选比较恢复硬约束、配送延误、中继代理压力、完工时间、能耗的顺序；代理压力不再排在配送及时性之前。
- 新增 `--full-audit`：100 s 是搜索/MILP 预算；严格密检与闭包仍执行，因此总墙钟可以超过 100 s。不加该开关且剩余时间不足时，候选保持 `pending_continuity_audit`，不得标记为可行。

## 复现实验与结果

```text
C:\ProgramData\Anaconda3\python.exe members/weiliu/Q3/code/run_alns_q3.py --data-root problem/数据 --output-dir members/weiliu/Q3/results_alns_q3_refined_full_v2_20260925 --budget 100 --seed 20260924 --full-audit
```

从仓库根目录运行。结果见 `results_alns_q3_refined_full_v2_20260925/global_audit.json` 与 `q3_gate/gate_audit.json`。本次实际墙钟 185.76 s，其中中继门禁及严格审计 152.99 s。ALNS-Q2 自身给出 24 架次、80 箱准时、运输完工 6374.35 s，但中继代理压力仍为 5，未作为最终 Q3 候选。门禁选择了 **WHLi Q2-v5 历史暖启动经本轮反馈排序后的运输方案**；独立运输核验通过。

对该候选，本轮重新生成并审计的联合方案：22 个运输架次、3 个中继架次、使用 2 架中继机；80 箱满足硬时限，联合完工 10137.80 s，联合能耗 78.33648 kWh；0.5 s 密检 0 断链，0.05 s 关键时段最小余量 +0.04170 dB。`q3_gate/assembled.json` 为本轮重新装配方案。结果数值与 WHLi 已有优化方案相同，故根目录 `selected_q3_solution.json` 仍按词典序比较规则选择原有 WHLi 方案，并明确标为 `pre_existing_whli_incumbent`。**本轮没有发现优于该历史方案的新运输解**，也不应把历史种子包装为独立发现。

下一步应对仍有 5 个代理压力单元的 ALNS-Q2 候选进行以中继可行性为目标的路线组批/时刻协同修复，而非仅调换顺序；并对 0.0417 dB 的小余量做坐标、DEM 和时间采样敏感性检验。
