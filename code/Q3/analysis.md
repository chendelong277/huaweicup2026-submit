# Q3 分析

> **三分钟摘要**：本文档说明问题三的总体思路：在问题二的运输方案上增加连续通信约束，先逐时间片判断运输无人机能否直连网关 G01，直连失败的路段再搜索中继无人机的位置和高度来补覆盖。实验结果是 198 个时间片通信全覆盖，但 2 架中继无人机库存下服务时间会冲突、2 箱首批物资超时约 19.8 秒，所以它定位了瓶颈，而不是给出最终可行解。术语看不懂可查仓库根目录 `shared/glossary.md`。

问题三在 Q2 无通信运输方案上增加连续通信约束。运输无人机的爬升、巡航、下降和交接阶段均需要保持与 G01 的直连，或通过一架中继形成运输机—中继—G01 的两跳链路。由于题面明确不允许中继多跳，中继覆盖可以转化为“运输轨迹时间片—候选中继位置/高度”的集合覆盖问题。

本实现采取两阶段基线：首先固定 Q2 运输路线和相对时间，基于 DEM 与双向链路预算逐时间片判断直连；其次对直连失败片段搜索候选中继位置和离地高度，并以覆盖片段数、最小链路余量、飞行能耗的词典序选取候选。最后将中继服务窗口、能源组件和充电周转写入资源审计。

实验结果显示，通信层面 198/198 个时间片均得到直连或单中继保障，但仅有 2 架中继无人机时，若不改变 Q2 运输实体机时序，中继服务窗口会发生冲突。对运输任务做确定性时序修复后，S002 的 2 个首批箱仍比 3600 s 晚 19.8 s。该结果用于定位 Q3 的主要瓶颈，不虚构为最终联合可行解。
