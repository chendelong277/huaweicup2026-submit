# Q2 双目标 Pareto-ALNS（mo-r1）算法说明

> **三分钟摘要**：这个文档介绍一个实验性变体 mo-r1：把期望送达时间从硬要求降回软目标，改用双目标 Pareto 方法求解。实验结论是否定的——在本题数据上两个目标方向一致，Pareto 前沿缩成一个点，相对字典序方法没有额外收获，文档据此建议论文改展示其他目标冲突。这是对照实验记录，不是主线方案。术语看不懂可查仓库根目录 `shared/glossary.md`。

在 chendelong E005（字典序、硬零延误）基础上改造：**期望送达时间降回软目标**，以 (加权延误 WT, makespan) 双目标做非支配档案式 Pareto-ALNS。

## 与 E005 的差异

| 组件 | E005 alns_plain | mo-r1 |
|---|---|---|
| 期望时间口径 | 提升为硬约束（ZeroDecoder，WT 恒 0） | 软目标；base `Decoder` 只管原始硬截止（医疗/首批等） |
| 目标 | 字典序 (WT=0 → makespan → 架次 → 能耗) | min (WT, makespan) 非支配 |
| 接受准则 | 字典序归一化劣化退火 | 支配→接受；互不支配→接受；被支配→按双目标归一化劣化退火，scale=(174000, 6400)，T=0.012·(1−进度)²+0.00005 |
| 档案 | 单最优解 | 非支配档案（`add_archive`，limit 32，拥挤度剪枝） |
| 算子与权重 | 8 基础算子、w←0.95w+0.05r | 同；奖励改为档案语义（支配插入 8 / 非支配插入 3 / 接受 1 / 拒绝 0.2） |
| 停滞重启 | — | 连续 80 次无档案插入则重启为档案随机成员 |

编码、解码器、8 个基础算子、评估器全部复用 `members/chendelong/pipeline/`（未修改任何文件；Python 3.8 通过 meta-path loader 只读兼容其 3.9+ 注解语法）。

## 实验结论（详见 `results_mo/README.md`）

3 种子 × 120 s、约 168 万次评估：前沿塌缩为单点 **(WT=0, makespan=6346.43 s, 24 架次, 70.91 kWh)**，支配 WHLi 三个锚点、被 E005 alns_plain (0, 6043.32) 支配。**本实例中 WT 与 makespan 实质同向，双目标 Pareto 相对字典序无增量价值**；建议论文改展 WT×能耗/架次 或 WT×通信可行性 的冲突。

运行：`python code/run_mo.py --budget 120 --seeds 0 1 2`（默认输出 `results_mo/`）。
