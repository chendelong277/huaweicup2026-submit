# Q2 假设与待确认事项

> **三分钟摘要**：这个文档列出 Q2 解题时自己定的六条假设，比如返航安全余量取 20%、哪些时限算硬要求、电池怎么算占用。读者需要知道的关键一点：结果是固定随机种子下的启发式可行解，不是全局最优；如果官方口径变了，Q1 到 Q3 都要重算。术语看不懂可查仓库根目录 `shared/glossary.md`。

1. 返航安全余量沿用 Q1 和附件默认值 20%。
2. 运输无人机附件未给出独立“架次周转时间”，因此固定准备时间计入每架次，无人机返回 O01 后即可进入下一架次的准备阶段；电池仍须完成规定充电后才能复用。
3. 医疗物资的期望送达时间按题意作为硬要求；首批保障货箱使用首批截止时间作为硬要求；其他物资期望时间只计入软延误。
4. 电池任务占用区间按架次完整开始至返回 O01 计算，包括准备、飞行和交接，属于保守资源口径。
5. 结果是固定随机种子 `20260923`、540 s ALNS 搜索预算下的启发式可行解；未计算精确下界，不称为全局最优。当前未全面搜索跨服务区合并邻域。
6. Q1 的能耗解释继续有效：水平能耗按“可用能量×距离/等效航程”，爬升附加能耗按重力势能除以效率；若官方给出不同公式，Q1 至 Q3 均须重算。
