# Q2 算法 v2 说明

> **三分钟摘要**：这个文档说明 Q2 算法 v2 相比之前改了什么：硬约束优先的目标顺序、引入外部方案做暖启动但全部重新核算、新增跨服务区重组算子、修复顺序被覆盖的 bug。文末是本次运行的实际结果：80 箱零硬约束违约、24 架次，192 项审计全部通过。注意通信可行性仍要留给 Q3 单独审计。术语看不懂可查仓库根目录 `shared/glossary.md`。

## 核心改动

1. 采用硬约束优先的词典序目标：硬约束违约数 → 加权配送延误 → 全部任务完成时间 → 架次与能耗。
2. 接入 chendelong `q2_full/seed_1` 方案作为候选暖启动，但不直接信任其指标；所有路线、载荷、体积、能耗、SOC、充电和资源占用均由当前 Q2 解码器重新计算。
3. ALNS 增加跨服务区重组算子，支持同时拆分/重组多个服务区的货箱批次。
4. 修复架次顺序层每轮被静态排序覆盖的问题，使交换、插入后的顺序持续继承；结构层和顺序层交替搜索。
