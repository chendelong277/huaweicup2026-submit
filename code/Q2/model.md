# Q2 数学模型与求解算法

> **三分钟摘要**：这个文档是 Q2 的数学模型和算法说明，写给要看公式的人。内容依次是路线与载荷约束、时间与送达规则、电池充电规则、多目标比较顺序，以及分层交替式 ALNS 算法流程。文末给出本次求解的实际结果（24 架次、零时限违约）并明确不宣称全局最优。

## 1. 路线与载荷

每个架次 $p$ 的路线为 $O01\to i_1\to\cdots\to i_k\to O01$。货箱 $b$ 只能分配一次。设到达节点 $i_r$ 前的剩余载荷为 $q_{pr}$，投送后按该节点货箱质量递减。每个航段使用 Q1 的等效航程与爬升附加能耗函数计算 $E_{gij}(q_{pr})$。

架次必须满足

$$q_{pr}\le Q_g,\qquad v_{pr}\le V_g,$$

$$\sum_{(i,j)\in p}E_{gij}(q_{pij})\le (1-\rho_g)E_g^{use}.$$

## 2. 时间与送达

架次持续时间包含固定准备、逐箱装载、每段爬升/巡航/下降、各服务区基础交接和逐箱交接。货箱送达时刻取对应服务区交接完成时刻。首批保障货箱以附件首批截止时间为硬约束；全部医疗物资以期望送达时间为硬约束；其他物资的期望时间进入加权延误

$$F_1=\sum_b w_b\max(0,t_b-\hat t_b).$$

## 3. 资源与充电

架次分配同机型实体无人机和共享电池。任一无人机或电池的占用区间不得重叠。任务后 SOC 为

$$SOC^{end}=1-E_p/E_g^{use}\ge\rho_g.$$

若 $SOC<0.9$，充电时长为快速段与慢速段之和；若 $SOC\ge0.9$，只计算慢速段。下一架次开始时刻不得早于充电完成时刻。

## 4. 多目标顺序

解的比较采用词典序：

1. 硬时限违约数；
2. 优先系数加权延误；
3. 最大完工时间；
4. 架次数；
5. 总能耗。

硬约束不通过的低能耗方案不会覆盖可行方案。

## 5. 算法

先以 Q1 组批为基线排程，再按硬截止时间、医疗/首批标志和应急优先系数生成可行初解。外层为分层交替式 ALNS：随机或针对迟到服务区重组一至两个服务区的货箱批次，并重新选择可行机型；顺序层对架次执行次序作移动、交换与插入。每个候选由资源解码器选择实体无人机—同型电池组合，计算完整的送达、能量、SOC、充电和资源时间线。算子权重每 100 次迭代更新；仅在硬违约数不变时允许有限退火式接受。固定种子 `20260923`，搜索时限 540 s，本次完成 255382 次迭代。

搜索期间同时维护外部档案：硬约束通过的候选才可入档，档案仅按前两个目标 $(WT,C_{\max})$ 的最小化非支配关系保留全部非支配点；架次数、能耗、迭代号和发现时刻作为附加字段记录。结果文件为 `results_v2/pareto_archive.json`、`pareto_front.csv` 和 `pareto_front.pdf/.png`。

当前 HD-ALNS 结果为 24 架次、硬时限违约 0、加权延误 0、最大完工 6374.351717 s、能耗 70.716666 kWh；不宣称全局最优。
