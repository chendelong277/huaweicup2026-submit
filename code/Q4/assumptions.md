# Q4 假设与口径记录

> **三分钟摘要**：这份文档记录问题四求解中采用的 7 条假设与口径（A1–A7）：用哪份问题三定稿方案做输入、各类资源占用时间怎么算、按什么优先级选解（与其他两位成员不同，两种口径的结果都已给出）、算法参数来源等。其中 A1 的通信复检状态和 A7 的几个细节仍待统一负责人确认。术语看不懂可查仓库根目录 `shared/glossary.md`。

- **A1 冻结输入**：使用 `members/WHLi/Q4/results/frozen/`（CSV 导出）。依据：本成员 Q3 最新主线（results_alns_q3_refined_full_v2_20260925）`selected_source=pre_existing_whli_incumbent` 且 `relay_gate_status=fully_audited_feasible`，最终选定方案与该 frozen 同源。潜在偏差：WHLi 侧 meta 标注 `retimed_stage5_pending_dense_check`，稠密通信复检状态待确认；分区结论对时刻小扰动不敏感（峰值并发由区间结构决定），但严格性待统一负责人裁决。
- **A2 资源核算口径**（与 WHLi `q4_resources.py` 审定口径一致，已经交叉核对）：电池占用含两段式充电时间（T_full = 1800/2400/3000 s）；中继无人机占用到 ready（含 300 s 周转）；能源组件占用含 1800 s 充电；跨组中继任务按组保守复制（位置与服务窗不变）。半开区间，端点相接不算并发。
- **A3 词典序口径（与 §3.5 的关系）**：§3.5 主链的 WT/makespan/架次/能耗在 Q4 冻结分区下是不变量（代码断言并在档案留痕），Q4 判别层级扩展为 硬违约→总缺口→中继复制→均衡比→冗余。这与 WHLi 推荐键（零中继复制→中继需求→缺口→均衡→冗余）和 chendelong 双口径均不同：本口径下 K=2 最优为 {S002}|其余（缺口 3），而 WHLi 推荐为 RS02 簇拆分（缺口 6、均衡 1.385）。两种口径结果都在 `enumeration_summary.json` 中给出（`lexicographic_best` 与 `whli_recommended`），供统一负责人裁决论文主线。待确认：§3.5 是否应对 Q4 豁免或改写判别层级。
- **A4 退火与接受准则参数**：沿用 ALNS-Q3-V2 的 T0=0.12、衰减 0.99985、侧向阈值 0.08。接受判定基于固定标量化 sa = 100·shortage + 10·relay_extra + balance + 0.01·redundancy 的**相对**变化率，量纲无关，故 V2 参数可直接迁移；该标量化仅用于温度尺度，不参与最终选解。敏感性：未单独扫描，如需可用 `--budget` 放长验证稳健性（5 种子一致性已验证）。
- **A5 工作量定义**：组工作量 = 组内架次 (ret−start) 时长之和（与 WHLi 一致，便于交叉核对）。不包含中继架次时长；若论文需要含中继的口径，需重跑并注明。
- **A6 档案维护规则**：档案上限 32。调试中发现并修复一个关键缺陷：原"按均衡比最差弹出"的截断会恰好把词典序最优解（缺口最小但均衡比最高）驱逐出档，导致长预算运行反而丢失最优。现规则为**冠军保护式多样性淘汰**：永不淘汰当前词典序最优条目，其余条目中弹出均衡比最差者；同时主循环独立维护 best-ever 候选（与容量受限的档案解耦），最终选解取 best-ever 与档案的并集最优。由于本问题非支配前沿 ≤12，截断实际很少触发，但该缺陷在任何触发截断的场景都会致命，特此留痕。
- **A7 待确认问题**：(a) 均衡比用 max/mean（WHLi 口径），chendelong 亦用 max/mean，保留；(b) `partition_result.csv` 的组级工作量按箱质量份额摊到服务区（沿用 WHLi 写法），若模板只需组级总量可直接汇总；(c) 缺口原因文本为中文短语，与 WHLi 风格一致。
