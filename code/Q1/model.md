# 问题一数学模型与算法

> **三分钟摘要**：本文档是问题一的数学模型与算法说明：航段飞行高度怎么从地形算出来、能耗公式怎么写、每个机型对每个服务区最多能安全载多少货、货箱怎么分批次装，以及求解后怎么自动复核。组批用动态规划枚举全部可行装箱方式，得到所选目标下的精确最优解，不是碰运气的近似结果。术语看不懂可查仓库根目录 `shared/glossary.md`。

## 1. 航段几何

对服务区 i，去程和返程均采用 O01 与 Si 的水平直线。程序使用栅格 supercover 遍历，纳入直线相交或触及的全部 DEM 像元。设沿线最高地面高程为 Hmax，则计划巡航海拔为

$$H_{i}^{cruise}=H_{i}^{max}+50.$$

O01 作业高度为其地面海拔，服务区作业高度为地面海拔加 30 m。由此得到去、返程的爬升高度、下降高度和水平距离。

## 2. 载荷相关能耗

机型 g 在有效载荷 q 下的等效航程采用题面公式

$$L_g(q)=L_{g0}-(L_{g0}-L_{gF})(q/Q_g)^{3/2}.$$

本实现对航段 i→j 采用

$$E_{gij}^{hor}(q)=E_g^{use}\frac{d_{ij}}{L_g(q)},$$

$$E_{gij}^{up}(q)=\frac{(m_g+q)g h_{ij}^{+}}{3.6\times10^6\eta_g},$$

$$E_{gij}(q)=E_{gij}^{hor}(q)+E_{gij}^{up}(q).$$

下降附加能耗按题面取 0。单点往返时去程载荷为批次总质量 q，返程载荷为 0。

## 3. 最大安全载荷

对每个机型 g 和服务区 i，求

$$\max q_{gi}$$

满足

$$0\le q_{gi}\le Q_g,$$

$$E_{g,O01,i}(q_{gi})+E_{g,i,O01}(0)\le(1-\rho_g)E_g^{use}.$$

等效航程随载荷单调下降，因此往返能耗随载荷单调增加，可用二分搜索稳定求解。体积不参与“连续质量载荷”定义，而在具体货箱组批中作为独立硬约束检查。

## 4. 货箱组批模型

对每个服务区独立求解。设该区货箱集合为 B_i，可行批次模式集合为 P_i。每个模式 p 包含一个货箱子集和一个机型，且预先通过质量、体积和能量检查。令 x_p 为是否选择模式 p，则

$$\sum_{p:b\in p}x_p=1,\quad \forall b\in B_i,$$

$$x_p\in\{0,1\}.$$

主目标采用词典序最小化

$$\left(\sum_p x_p,\ \sum_p E_p x_p,\ \sum_p T_p x_p\right).$$

累计作业时间包含固定准备、逐箱装载、去程飞行、基础交接、逐箱交接和返程飞行。Q1 不考虑实体无人机和电池的并行排程，因此这里求和而非 makespan。

## 5. 精确算法

每个服务区最多 15 箱。程序以位掩码表示货箱子集：

1. 枚举非空子集，计算质量、体积和三机型往返能耗。
2. 保存全部可行“子集—机型”模式。
3. 对未分配集合 R，固定其中最低位货箱，枚举所有包含该货箱的可行子集 P。
4. 递推 f(R)=min{cost(P)+f(R\P)}，按指定词典序比较。
5. 记忆化全部状态并回溯得到批次。

固定最低位货箱避免同一集合划分因批次顺序不同而重复枚举。由于枚举了全部可行子集，动态规划得到所选词典序目标下的精确最优解。

## 6. 审计规则

求解后从批次结果反向读取原始货箱，再计算一次质量、体积、能耗和时间，并检查：

- 所有 80 箱恰好出现一次；
- 每个批次仅含一个服务区的货箱；
- 批次质量和体积不超过所选机型；
- 往返能耗不超过安全能量上限；
- CSV 中的批次合计与重算值一致。
